Sourcing Helper — Settings

Extraction engine
Claude API

Key is stored in chrome.storage.sync and sent only to api.anthropic.com from the extension's service worker.

People Data Labs (live people search)

Enables the "Find people at this company" buttons in the popup. Get a key at dashboard.peopledatalabs.com (free tier available). Person Search may require a paid/sandbox plan on some accounts — the popup shows the API error if a call is rejected.

Email finder (waterfall)

Tries each source in order and stops at the first address a verifier confirms. Every key is optional: with none, it still guesses the common formats (first.last@, jdoe@, ...) from the company's domain, unverified. A verifier key is what turns a guess into a confirmed address. All have free tiers.

Getting a key: sign up on the provider's site, open its API page, copy the key, paste it below, and click Save, then Check keys.

Steps (run top to bottom; the People Data Labs key above is also used here)

Each verification and finder lookup uses one credit from that provider. Found emails and each company's email format are remembered on this device, so repeat lookups are free.
